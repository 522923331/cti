# Phase 4 验证记录

时间：2026-11-09。

## 做了什么

- 新增独立模拟账本。账户类型只接受 `PAPER` 和 `CUSTOM`。余额拆成可用、冻结和总额，总额等于前两项相加。
- 每次余额变化写一条流水。流水按账户和请求号唯一，重复请求直接返回，不第二次扣款。
- 持仓用加权平均成本。买入成本是成交额加手续费。卖出收入是成交额减手续费。全部卖出后数量和成本都是 0，平均成本留空。
- 金额用 Decimal，记账保留 12 位小数。余额更新带版本号，并在事务里锁住账户行。
- 研究账户 `CTI_TREND_V1` 仍在原来的三张表里，这一阶段的接口不写它。

## 核对

- 开户 100，买入 2 个、价格 10、手续费 1，成本金额 21，平均成本 10.5，可用余额 79。同一请求再买一次，持仓仍是 2。
- 市价标成 11 时，市值 22，未实现盈亏 1。标价不产生现金流水。
- 以价格 12、手续费 1 全部卖出后，数量 0，成本 0，已实现盈亏 2，可用余额 102。流水现金变动合计等于余额。
- 另一个账户初始 20。取出 21 被拒绝，余额仍是 20。停用后继续入金也被拒绝。
- `CTI_TREND_V1` 现金和权益仍是 103888.410658328862。V1.0 信号仍是 5600 行，其中没有 `EXIT`。情报评分仍是 5600 行。
- Flyway V12 成功。账户页和账户明细页都返回 200。

## 边界

这一阶段只记账，不计算目标仓位，也不生成模拟订单。订单、成交回报、配置方案和组合风险快照留在下一阶段。
