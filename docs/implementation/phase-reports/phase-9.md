# Phase 9 验证记录

时间：2026-11-09。

## 做了什么

- 研究助手先识别问题，再按固定查询读取已经落库的融合、情报评分、实验、健康度和正式参数。问题文本不会拼进 SQL。
- 没有模型服务。每条回答的解释都是“未能生成解释”，旁边给出查询到的字段。
- 问题里出现、但查询结果里没有的数字记入拒绝列表，不写进引用值。查不到的记录保持空，并标明数据缺失。
- 要求改参数、下单或改余额时直接拒绝，写入列表为空。
- 会话和证据写在 `ct_ai_research_session`、`ct_ai_research_evidence`。证据记下查询时间、数据范围、来源表和版本。
