# Phase 5 验证记录

时间：2026-11-09。

## 做了什么

- 新增 V1.2 配置计算。单币权重不超过 20%，山寨币合计不超过 40%，现金至少留 15%。趋势分再高也不能突破单币上限。
- 评分或波动率缺失、波动率为负时，正式配置直接拒绝，不写方案。已确认的 `BEARISH` 不给出买入目标。
- 模拟订单支持市价和限价。市价用开盘价加 8 个基点滑点，手续费按成交额计算。限价未触及时保持未成交。同一根 K 线同时碰到止损和止盈时只卖在止损。
- 同一个账户、策略、信号和方向只能有一张订单。现金不够时订单记为拒绝，余额不变。成交和手续费写入原有流水。
- 研究账户和 V1.0 回测没有被改写。

## 边界

规格没有给出评分门槛、波动率下限、ATR 倍数和最小下单金额，正式配置必须自己带上这些数。VaR、CVaR 没有置信度，快照里保持空，不用于下单。未成交的限价单不冻结现金。
