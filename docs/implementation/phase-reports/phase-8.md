# Phase 8 验证记录

时间：2026-11-09。

## 做了什么

- 参数实验按验证集的风险调整收益选参。规格没有定义这个收益怎么算，所以不另造公式，调用方必须给出 `validation.riskAdjustedReturn`。
- 回撤、最少交易次数和费用占比是约束。不合格的参数组保留，但不能当选。测试集不参与排序，只检查被选中的那一组是否也满足同样约束。
- 时间跨度够 24 个月训练、6 个月验证、6 个月测试，等级才是 `FULL`。更短的记 `SHORT_WINDOW`，不能标记通过。走步折按每 3 个月滚动记在实验里。这一阶段不重跑 V1.0 回测。
- 健康度按请求里的 90 日回撤门槛判断。超过后是 `DEGRADED`；连续恶化达到次数后是 `SUSPENDED`。动作只有 `ALERT_ONLY`，不改正式参数。
- 新结果写在 `ct_optimization_run`、`ct_optimization_result` 和 `ct_model_health_snapshot`。
