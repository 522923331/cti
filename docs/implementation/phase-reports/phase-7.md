时间：2026-11-09。

## 做了什么

- 市场状态拆成方向和波动。方向是 `BULL`、`BEAR` 或 `SIDEWAYS`。波动是 `LOW`、`NORMAL` 或 `HIGH`。
- 高波动只写在波动状态上，不把方向改成高波动。
- 融合分用有效策略的分数和权重。缺分数的策略剔除，其余权重重新归一化，合计仍是 1。缺失策略的贡献留空，不按 0 分。
- 没有单独给出买入分数门槛时，融合信号保持 `NO_TRADE`。看多的策略再多，也不会直接变成买入。
- 新结果写在 `ct_regime_history`、`ct_ensemble_config` 和 `ct_ensemble_result`。不改 V1.0 的市场状态表。
