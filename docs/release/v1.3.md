# V1.3 研究版发布说明

日期：2026-11-09。这是本地研究系统，只做模拟，不做真实交易。

- V1.0：日线研究、评分、信号、研究账户和回测。
- V1.1：U 本位公开行情、币安公告、情报评分和日报。链上没有供应商，保持关闭。

助手没有模型服务。解释固定为“未能生成解释”，只引用查询到的字段。

## 启动

Linux 服务器的安装、systemd 和每日任务见 `docs/release/linux-deploy.md`。下面是开发机的启动方式。本机 8080 上有别的服务。CTI 使用 8081，Python 使用 8090。

```bash
cd cti-server
export JAVA_HOME="/Users/k02/Library/Java/JavaVirtualMachines/ms-17.0.15/Contents/Home"
export PATH="$JAVA_HOME/bin:/opt/homebrew/opt/maven/bin:$PATH"
export CTI_DATA_DIR="/Users/k02/quant/cti/data"
java -jar cti-api/target/cti-api-1.0.0-SNAPSHOT.jar
```

```bash
cd cti-quant
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8090
```

MySQL 库名 `cti`，用户 `cti`。Redis 在 6379。没有 Docker 时不要执行 `docker compose`。

## 页面

打开 http://127.0.0.1:8081/ 。旁边还有排行、单币、信号、组合、回测、策略、日报、监控、情报、账户、研究策略、融合、实验和助手。

健康检查是 `GET /api/v1/admin/system-health`。XXL-Job Admin 没启动时，MySQL 和 Redis 仍是 `UP`，任务调度是 `DEGRADED`，总状态也是 `DEGRADED`。任务用页面或 `POST /api/v1/admin/jobs/{name}/trigger` 手动触发。

- `CTI_TREND_V1` 的样本内回测验收是 `passed: false`。总收益 0.038884106583，最大回撤 -0.028838266719，27 笔交易。同一结果存了两份。

- V1.3 的 48 个月实验用的是请求里给出的指标，等级 `FULL`。两个月的实验是 `SHORT_WINDOW`，通过标记是 0。

## 仍然关闭

## 回滚

Flyway 现有 V1 到 V17，其中 V2 和 V6 是 Java 迁移。没有向下脚本。

回滚步骤：

1. 停掉 8081 上的 Java 进程和 8090 上的 Python 进程。不要动 8080。
2. 用迁移前留下的 MySQL 备份恢复 `cti`。这次发布没有新建备份。
3. 换回上一版 jar 和对应的 Python 代码，再按上面的命令启动。
4. 不要删除 `flyway_schema_history` 里的行来假装回滚。库结构还在时，旧程序会和表对不上。

重复启动当前版本时，Flyway 校验 17 个迁移，然后显示 schema 已是最新，不再执行。
